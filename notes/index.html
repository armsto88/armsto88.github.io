A few notes from projects I’m actively developing, testing and learning from.

October 2026

  1. FieldMesh

    1. FieldHub V2 — Sensor Bring-Up

      • Four I²C sensor ports verified with an SHT40, including at 400 kHz
      • ADS1015 inputs within about 1% of a reference meter, no crosstalk
      • Reed input works, but its GPIO moves in the next revision
      • Still to test: ESP-NOW, RTC backup retention, longer wake cycles

    2. FieldHub V2 — Scaling the Network

      • First test: controlled hub boot delays, two nodes against Hub V2
      • Goal: measured node capacity instead of theoretical estimates
